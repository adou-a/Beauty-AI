# Beauty-AI Project Context

## 项目目标

Beauty-AI 是 AI Agent Developer Roadmap 的主实践项目。

最终目标：

-   完成一个可展示、可测试、可部署的垂直领域 AI Agent
-   建立从零开发 Agent 的能力
-   将能力迁移到其他领域 Mini Agent

核心方向：

-   护肤成分知识库
-   LLM 接入
-   AI 分析
-   Tool Calling
-   Workflow
-   Memory
-   RAG
-   API 产品化

## 当前学习方式

-   项目实践优先
-   每个阶段明确目标和验收标准
-   理解底层原理
-   不盲目堆框架
